## 2. 검증 (실측)

조용한 방, 마이크 켜진 실사용 상태, −18 dBFS 톤:

| 스냅샷 | 조용할 때 | PC를 3/4로 재생 | PC를 1/2로 재생 |
|-----|-----|-----|-----|
| 4 REC | −78.3 dBFS | **−78.3** (기여 0) | −72.2 |
| 2 TALK | −74.7 dBFS | −78.3 (기여 0) | **−38.2** (의도대로 섞임) |

마이크 경로를 전부 끊고(레벨 0 · FX 센드 0 · 뮤트) 잰 전기적 누설은 REC에서 −84.3 dBFS로 무음 바닥과 같았다.

SingPromfter가 쓰는 ffmpeg 인자 그대로 입력 장치를 열어 확인:

| 믹서 상태 | MAIN L/R | 판정 |
|-----|-----|-----|
| 스냅샷 1 (평소) | −96.7 dBFS | 디지털 무음 — 마이크 레벨이 0이라 정상 |
| 스냅샷 4 (REC) | −89 ~ −64 dBFS | 마이크 살아 있음(앱의 죽은 장치 기준 −85 통과) |

`apply_slot`이 매 호출마다 `config.load_config()`를 부르는 것을 코드로 확인 — 설정 변경에 앱 재시작이 필요 없다.

## 3. 새로 알아낸 것

- 🔴 **FLOW 8이 PC에 내주는 녹음 입력은 `MAIN L/R` 하나뿐이다.** dshow 열거 실측 결과 오디오 입력은 RØDE NT-USB Mini · Razer Barracuda X 2.4 · MAIN L/R 셋이고, USB Out 3/4는 **출력** 엔드포인트라 ffmpeg로 잡을 수 없다. 반주를 따로 캡처하는 2채널 녹음은 이 장비로 불가능하다 — OBS처럼 출력 엔드포인트를 WASAPI 루프백으로 받는 프로그램만 가능하다.
- 🔴 **SingPromfter 설정은 슬롯 4에서만 맞다.** 슬롯 1·2·3은 USB 1/2가 메인 믹스로 들어가므로 그대로 녹음하면 반주가 보컬 트랙에 섞인다(−38 dBFS 실측).
- 🔴 **믹서가 BLE 광고를 스스로 끊는다.** 폰·앱을 의심하기 전에 PC에서 BLE 스캔으로 `FLOW 8 LE`가 잡히는지 보고, 안 잡히면 전원 재기동이 유일한 복구다.
- 🔴 **오디오 측정은 마이크가 오염시킨다.** 마이크가 켜져 있으면 테스트음을 공기로 주워 담아 전기적 누설처럼 보인다.

## 4. 남은 것 (사용자 확인 필요 — 체크리스트 밖)

- 슬롯 4에서 헤드폰으로 반주와 자기 목소리가 들리는지 귀 확인. 모니터 경로라 측정 불가.
- SingPromfter 녹음 지연 보정 재조정. 입력 경로가 USB 마이크 → 믹서로 바뀌었다. 한 곡 받아 보고 보컬이 늦으면 올리고 앞서면 내린다(설정 > 녹음, 5 ms 단위).
- 노래할 때 실제 레벨이 클리핑되는지. 앱 미터가 빨개지면 1번 슬라이더부터 내린다.
- 마이크 슬라이더 실전 위치 확정 → 폰 연결해 스냅샷 2·3·4 재저장.
